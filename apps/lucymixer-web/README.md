# LucyMixer

A browser video and photo editor for social media (reels, Shorts, posts) and local files. Everything is
rendered on the user's computer (canvas, WebGL2, MediaRecorder); media is never uploaded.

- `/` — landing page; `/editor` — the editor; `/desktop` — LucyCut Pro / LucyStudio (4K+, coming soon).
- `/auth/callback` — Google sign-in through Supabase (PKCE). Signing in is free and shows the
  favorites and history saved with the Fullscreen Viewer extension (links only).
- `/api/emoji/[cp]` — fetches an animated Noto Emoji GIF for stickers when the browser can't.

## Limits

Media up to 2560×1440. Larger media (4K+) is refused and points to the desktop app.

## The editor code

`public/editor/*.js` is the plain-JS editor, moved from the Firefox extension. The files are classic
scripts sharing the `IgfvEditor` global; `src/components/EditorHost.tsx` loads them in order and opens
the editor with the web host (drafts in IndexedDB, Supabase sources, downloads). Bump
`EDITOR_VERSION` there whenever these files change.

## Run

```sh
corepack pnpm install
corepack pnpm dev:lucymixer        # http://localhost:3001
corepack pnpm build:lucymixer
```

Copy `.env.example` to `.env.local`. It holds only public values: the Supabase URL and its
publishable key. In the Supabase dashboard → Auth → URL configuration, allow
`http://localhost:3001/auth/callback` and the production callback URL as redirect URLs.
